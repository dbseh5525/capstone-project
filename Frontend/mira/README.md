# MIRA

가족의 일상과 마음을 이어 주는 Flutter 앱입니다.

## 이름에 담은 의미

**Moments In Resonance, Always**

> 함께한 순간이 서로의 마음에 오래 울리도록.

MIRA에 부여한 브랜드 의미입니다. 평범한 하루의 사진, 짧은 안부, 함께 돌보는 작은 친구를 통해 가족의 순간들이 서로에게 닿고 오래 남는 경험을 지향합니다.

## 실행

저장소 루트에서:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File Frontend/mira/run.ps1
```

홈과 펫의 강아지 돌봄·성장, 4열 사진첩과 글·댓글·좋아요, 첫 이용 안내를 제공합니다. 사진첩과 강아지 상태는 현재 기기에 저장되며, 실제 가족 공유와 인증은 서버 연동이 필요합니다.

구조, 테스트, 개인정보 안내의 적용 범위는 [통합 문서](INTEGRATION.md)를 참고하세요.
